NusaStat — an original, offline national statistics site for Indonesia: population, economy, labour, prices and regions, with every figure sourced from Statistics Indonesia (BPS) and the APJII survey, and every chart drawn by the site's own canvas code. No network requests, no libraries, no build step. Open `app/index.html` through any static file server with `app/` at its root.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `app/` and `screenshots/` into the output directory and writes `dossier.json` with the vendored make.fun library.
